# 出荷通知プロンプト（拡張 Claude in Chrome 用）

出荷アプリ（ship.html）の「⑤ 出荷通知」が作る指示文の型。2026/11/9 に実際の出荷5件でテストし、確定した。

## 使い方
1. B2クラウドで伝票を発行する
2. B2用Excelで、今日出荷した行（「本日出荷」で絞った行）をコピーする
3. ship.html の⑤に貼る →「指示文をコピー」→ 拡張に貼る

## 店の見分け方（お客様管理番号＝注文番号）
| 店 | 注文番号の形 |
|---|---|
| Amazon | 3-7-7桁（例 250-xxxxxxx-xxxxxxx） |
| Yahoo!ショッピング | 8桁の数字 |
| BASE | 16桁の英数字 |

伝票番号は12桁の数字（ExcelのD列）。

## 到着予定日
- Excelの「お届け予定日」に日付があれば、その日。配達時間帯があれば時刻も（BASEだけ使う）
- なければ出荷日の翌日（北海道・沖縄・青森・秋田・岩手は翌々日）。目安

## 指示文の型
```
今日（{出荷日}）出荷した{件数}件の出荷通知を入力してください。
配送会社はすべて「ヤマト運輸（宅急便）」、出荷日は{出荷日}です。

【Amazon】https://sellercentral.amazon.co.jp/orders-v3/mfn/unshipped
未出荷の注文一覧で、下の{n}件をまとめて選び、「出荷通知を一括送信」で1つの画面にまとめて入力する（1件ずつ送信しない）。
出荷日 {出荷日}、発送元は「ZAZOU株式会社」
・{注文番号}　追跡番号 {伝票番号}

【Yahoo!ショッピング】{一括出荷の画面URL}
注文一覧で、下の{n}件をまとめて選び、一括の出荷処理で入力する（1件ずつ送信しない）。出荷日 {出荷日}。到着予定日も入れる（時刻の欄はない）。出荷ステータスは「出荷済み」
・{注文番号}　伝票番号 {伝票番号}　到着予定日 {到着予定日}

【BASE】https://admin.thebase.com/shop_admin/orders/
注文番号で開き、配送業者・追跡番号を入れて「発送済み」にする。
購入者へのメッセージは、テンプレート「ZAZOOマウス」を選び、出荷日・着荷予定日・到着時刻（指定があるときだけ）を入れる
・{注文番号}　追跡番号 {伝票番号}　出荷日 {出荷日}　着荷予定日 {到着予定日}　到着時刻 {時間帯}

決まり：
・店ごとに全件を入力して、出荷通知を送信する。終わったら新しいタブで次の店に進む（Amazon → Yahoo! → BASE の順）
・全部の店が終わったら、送信した内容をまとめて報告する
・注文番号と追跡番号の組み合わせを、画面で必ず照らし合わせる
・見つからない注文や、すでに通知済みの注文があれば、何もせず報告する
・ここに書いていない注文には触らない
・購入者の情報はどこにも書かない
```

テストのチェックを入れると「決まり」の最初の2行が次に変わる：
```
・テストです。店ごとに全件を入力し終えたら、出荷通知の送信ボタンの手前で止める（送信は押さない）
・止めたタブはそのまま残し、新しいタブで次の店に進む（Amazon → Yahoo! → BASE の順）
・全部の店が終わったら、店ごとの入力内容をまとめて報告する
```
（テスト時、Yahoo!の出荷ステータスは「出荷処理中」まで）

## 各店の画面の決まり（11/9 テストでわかったこと）
- Amazon・Yahoo!：「一括」と書かないと、拡張が1件ずつ送信してしまう
- Amazon：到着予定日の欄はない。発送元を「ZAZOU株式会社」にする
- Yahoo!：到着予定日の欄はあるが、時刻の欄はない
- BASE：購入者へのメッセージのテンプレートは「ZAZOOマウス」。出荷日・着荷予定日・到着時刻（指定があるとき）を入れる
- 画面のURLを指示文に入れる（ないと探し回る）。URLは⑤の設定で変えられる
