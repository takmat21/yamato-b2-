# ship-cli：出荷アプリと同じ変換を、ファイルから直接おこなう道具

朝の手順のうち「リフレッシュ → ドラッグ＆ドロップ → 変換 → 台帳に貼る」を、1回の実行に置きかえる。
出荷アプリ（`ship.html`）そのものを読み込んで動かすので、変換の決まりはアプリと同じ。

## 用意（PCで1回だけ）
1. Node.js（18 以上）を入れる
2. このフォルダで `npm install`
3. 出荷アプリを開き、「設定と履歴を書き出す」を押して `ship_state.json` を保存する（ご依頼主の設定・短縮ルール・処理済みの記録が入る）

## 使い方
```
node ship_cli.mjs --in <ダウンロードフォルダ> --state <ship_state.json> --out <出力フォルダ> --ledger <台帳.xlsx>
```
- `--in`：フォルダを渡すと、24時間以内（`--hours` で変更）の .txt・.csv のうち、Amazon・Yahoo!・BASE の注文ファイルだけを読む。同じ店のファイルが2つ以上あれば、新しいほうだけ使う
- `--state`：前に出した注文（処理済み）を除く。終わると、今回の分を足して書きもどす（前の物は `.bak`）
- `--out`：新しい分の `b2_new_日時.tsv`（確認用）と `yamato_b2_日時.csv`（B2クラウド取り込み用、Shift_JIS）
- `--ledger`：台帳（1枚目のシート）の最後の行の下に、新しい分を書き足す。書く前に `…_控え_日時.xlsx` を作る。エクセルで開いたままだと書けない
- `--dry-run`：何も書かず、件数だけ出す
- `--today` `--date YYYY-MM-DD`：出荷予定日が基準日より後の注文を外す

画面に出るのは、件数と注文番号だけ。お客様の名前・住所・電話は出さない。
